# 家庭维修事项

端口规划：`5114`

```bash
npm install
npm run dev
```

## 功能

第一版闭环：记录维修问题、按状态查看、更新处理状态、统计未完成预计费用，支持照片链接并使用 localStorage 保存数据。

保修跟进：

- 完工单填写**保修月数**和**完工师傅**（完工日默认今天，可改）。
- 同一位置在保修期内再次报事：新事项自动挂在原完工单下，状态先记**待返修**，暂不计入未完成费用。
- 接单规则：原师傅可直接接手；原师傅未接手前，其他人接单会被**退回**并提示「在途责任」；登记**授权人**后可换人处理，过程留痕。
- 旧记录没有保修资料时按**已过保**处理，可在卡片上补登保修。
- 工具栏可按 **待返修 / 已过保** 筛选。

## 代码结构（数据、规则、页面分开维护）

```
src/
├── main.js              # 控制层：事件绑定、串联存储与规则
├── data/store.js        # 数据层：localStorage 读写、旧记录归一化
├── rules/warranty.js    # 规则层：保修判定/挂靠/接单退回/换人/筛选/统计（纯函数）
└── ui/view.js           # 页面层：状态 → HTML，无业务写操作
```

规则层不依赖 DOM 和存储，可单独跑测试：

```bash
npm test
```
