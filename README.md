# 家庭维修事项

端口规划：`5114`

```bash
npm install
npm run dev
```

第一版闭环：记录维修问题、按状态查看、更新处理状态、统计未完成预计费用，支持照片链接并使用localStorage保存数据。

第二版保修跟进：

- 完工单登记保修月数和师傅，卡片上显示保内/已过保及到期时间，可随时补登或修改
- 保修期内在同一位置再次报修，新事项自动挂到原完工单下，状态记为待返修，暂不计入未完成费用
- 待返修单原师傅未接手前，其他人接单会被退回并提示在途责任；换人处理必须登记授权人并留交接记录
- 旧记录没有保修资料时按已过保处理
- 支持按待返修、已过保筛选

代码分层：`src/data.js` 负责数据读写与旧记录字段补全，`src/rules.js` 负责保修期、接单/换人、费用口径等规则，`src/main.js` 负责页面渲染与交互。
